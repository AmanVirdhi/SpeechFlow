# SpeechFlow 🎙️

**AI-Powered Speech-to-Text Application**

SpeechFlow is a full-stack web application designed to convert speech into text and provide an AI-powered experience through modern web technologies.

## 🚀 Project Overview

SpeechFlow aims to simplify audio-to-text conversion through an intuitive user interface and a Java-based backend, with Google Gemini API integration.

## 🛠️ Technology Stack

### Frontend
- React.js

- Vite

### Backend

- Spring Boot

- Google Gemini API

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/AmanVirdhi/SpeechFlow.git
cd SpeechFlow
```

### 2. Backend Setup

```bash
cd backend/speechflow-api
```

Configure the required environment variables before starting the backend.

Run the Spring Boot application using Maven or your IDE.

### 3. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

## 🔐 Environment Configuration

Keep API keys and sensitive credentials in environment-specific configuration.

Never commit API keys or secrets to GitHub.
